E-SIMS

the project worked on postgres for database,express and nodejs for backend and nextjs for frontend

## 1. Backend Setup & Execution

1. **Open a terminal** and navigate to the backend directory:
   cd backend

2. **Install dependencies:**
   npm install
3. **Database Configuration:**
   Ensure you have a `.env` file inside the `backend` folder with your PostgreSQL credentials.

4. **Initialize the Database (Migrations & Seeding):**
   Run the following commands to create the tables in your database and populate initial user data (Managers/Officers):
   npx prisma migrate dev
   npm run seed

5. **Start the Backend Server:**
   npm run dev
   _The backend should now be running on `http://localhost:5000`._

## 2. Frontend Setup & Execution

1. **Open a second, new terminal window** (leave the backend running) and navigate to the frontend directory:
   cd frontend/frontend

2. **Install dependencies:**
   npm install
3. **Start the Frontend Development Server:**
   npm run dev
4. **Access the Application:**
   Open your web browser and go to:
   http://localhost:3000

Once both servers are running, you can log in to the system at `http://localhost:3000/login`. Use the credentials generated by your backend seed script to access the Manager or Sales Officer portals.
